Statický web spolku **Aktivní škola z. s.** (IČO 22643354). Bez buildu, bez databáze – čisté HTML/CSS.

## Struktura
- `index.html` – úvod, o nás, kroužky, přihláška, kontakt, povinné údaje spolku
- `ochrana-osobnich-udaju.html` – zásady GDPR (návrh)
- `styles.css` – vzhled (barvy: oranžová = pohyb, modrá = digitál, zelená = tvorba)
- `CNAME` – vlastní doména pro GitHub Pages
